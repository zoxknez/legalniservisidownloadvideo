# Eksterni binarni fajlovi

Ovaj folder je opciono mesto za alate koje aplikacija traži u **Postavke → Sistem**:

| Fajl | Namena |
|------|--------|
| `device.wvd` | Widevine L3 CDM (kopira se u `~/.videodownload/device.wvd` preko UI) |

**Ne commit-ujte** `device.wvd` u Git — fajl je ličan i osetljiv. Koristite auto-instalaciju u aplikaciji ili upload u Postavkama.
