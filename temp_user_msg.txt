Evo ti kompletno uputstvo analiziraj ga i koristi eksterne izvore da bude sve savrseno :


HRTI Downloader - Vodič za korišćenje

Potrebni alati

Pre pokretanja, potrebno je imati instalirano:

Python 3.10+
yt-dlp — pip install yt-dlp
pywidevine — pip install pywidevine
xmltodict — pip install xmltodict
mp4decrypt (Bento4) — u PATH ili u folderu binaries/
mkvmerge (MKVToolNix) — u PATH ili u folderu binaries/
aria2c — opciono, za brže preuzimanje
Widevine L3 CDM fajl (device.wvd)


Instalacija Python biblioteka odjednom:
Code:
[Izaberi]
[Proširi]
pip install yt-dlp pywidevine xmltodict requests


Potrebni fajlovi

hrti_auth.py — modul za autentifikaciju
hrti_downloader.py — glavni downloader
hrti_browser.py — pretraživač sadržaja


Svi fajlovi treba da budu u istom folderu, zajedno sa device.wvd.

─────────────────────────────────────────

Prvo pokretanje — čuvanje kredencijala

Code:
[Izaberi]
[Proširi]
python hrti_downloader.py --save-credentials -u vas@email.com -p VasaSifra


Kredencijali se čuvaju u ~/.hrti/config.json i koriste automatski pri svakom sledećem pokretanju. Nije potrebno unositi ih ponovo.

─────────────────────────────────────────

Pronalaženje sadržaja

HRTI ne prikazuje ID videa u URL-u browsera, pa se koristi hrti_browser.py za pronalaženje ID-eva.

Pregled svih kategorija:
Code:
[Izaberi]
[Proširi]
python hrti_browser.py --list


Pregled filmova u kategoriji:
Code:
[Izaberi]
[Proširi]
python hrti_browser.py --cat domaći_filmovi
python hrti_browser.py --cat Strani_filmovi --page 2
python hrti_browser.py --cat krimići


Pretraga po naslovu:
Code:
[Izaberi]
[Proširi]
python hrti_browser.py --search "naziv filma"


Pregled svih epizoda serije:
Code:
[Izaberi]
[Proširi]
python hrti_browser.py --series 5
